## Análisis de necesidades · PRIMA

| Problema | Necesidad | Posible solución |
|---|---|---|
| Hosts desactualizados y mal configurados | Actualizarlos y configurados bien | Gestión centralizada de actualizaciones y configuración base |
| Dificultades para instalar la red en el hotel | Desplegar la red de forma rápida y ordenada | Plan de cableado y Wi-Fi por zonas |
| Problemas de ciberseguridad | Proteger los datos de clientes | Segmentación de red (VLAN), firewall y copias de seguridad |
| Web del hotel poco llamativa y desactualizada | Web atractiva y actualizada | Rediseñar la web paara que sea mas llamativa y atraiga a mas personas|
